# Jade

[![License](https://img.shields.io/github/license/AerafalDev/Jade)](LICENSE)
[![.NET](https://img.shields.io/badge/.NET-11-512BD4)](https://dotnet.microsoft.com/)

Jade is a cross-platform 2D game engine for .NET. A single C# code base targets desktop, mobile
and the web.

> **Status:** early development. Nothing is usable yet and no package has been published.

## Platforms

| Family | Platforms |
| --- | --- |
| Desktop | Windows, Linux, macOS |
| Mobile | Android, iOS |
| Web | WebAssembly |
